# Research ledgers

Curated research records for the OVNIS case corpus, one JSON object per line. Each file's schema is under
`schemas/research/`; the rules are in [`docs/RESEARCH_LEDGERS.md`](../../docs/RESEARCH_LEDGERS.md).

**To record research,** append a row to the matching ledger:

- Set `origin` to `CURATED`, and fill `recorded_by` and `recorded_at`.
- Cite the case or source-registry entry the claim rests on.
- Run `python3 scripts/validate_research_ledgers.py` before opening a pull request.

**Never delete a row.** Retire it by status instead: `REJECTED`, `SUPERSEDED` with `superseded_by`, or
`DROPPED`.

`manifestation_candidates.jsonl` is generated by `python3 scripts/dedupe_candidates.py --master-pairs`;
never edit it by hand. To decide a candidate pair, add a reviewed entry to
`manifestation_adjudications.jsonl`.
